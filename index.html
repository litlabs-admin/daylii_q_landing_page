How it works

Catalog in. Cited eligibility out.

A low-lift, file-based flow — you send the catalog, we return a determination for every SKU. No API required to get value; an optional read-only API adds live per-SKU lookups at checkout.

01 · Determine

Run the catalog

A cited verdict per SKU — eligible, ineligible, or LMN — sets the baseline, with confidence and reasoning on every line.

02 · Keep current

Re-grade as rules move

Continuous re-grading as IRS, CARES, FDA, and CMS guidance changes. The layer never goes stale.

03 · Audit

Export the record

Every SKU carries a verdict, citation, confidence, and reasoning — one clean record per item, ready for an auditor.
